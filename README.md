# 坦克大战 / Tank Battle

HTML5 坦克大战网页游戏，纯前端实现，无需任何依赖。

## 玩法 / Controls

| 按键 | 操作 |
|------|------|
| `↑` `↓` `←` `→` 或 `WASD` | 移动 |
| `Space` | 射击 |
| `P` | 暂停 |

## 特性

- 🎮 单人坦克对战，关卡制
- 🤖 敌人 AI（索敌追踪 + 随机巡逻）
- 🧱 可破坏/不可破坏墙壁
- 🎁 道具系统（速度提升、射速提升、生命恢复）
- 💥 粒子爆炸特效 + 屏幕震动
- 🔊 实时音效（Web Audio API）
- 📈 3 个内置关卡，难度递增

## 技术栈

HTML5 Canvas + CSS + JavaScript（单文件）
